# 实时风险决策引擎学习指南

一份面向高级后端工程师与架构师面试准备的中文静态学习网站。内容覆盖同步决策、特征依赖 DAG、配置生效、异步副作用、关键技术取舍和故障推演。

特征 DAG 章节进一步区分分支剪枝、单节点调用跳过与整次请求终止，避免把局部节省误解为全局提前返回。

## 内容边界

本站只包含原创的通用架构说明与伪代码，不包含任何真实项目的源码、模块名称、内部地址、配置、生产数据或部署信息。示例中的接口、字段和拓扑均为虚构教学模型，不用于描述任何特定组织的实际系统。

## 离线使用

直接双击 `index.html` 即可阅读。页面的样式、脚本和架构图全部内联，不依赖远程字体、CDN、接口或统计服务。

也可以在目录中启动本地静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 运行机制版

内容已重构为面向实现的通用手册：协议契约、分支裁剪、表达式缓存、配置快照、能力注册、依赖调度、优先级保护与异步动作。每个专题按输入、分支、输出、取舍、失败和面试追问组织，包含原创伪代码与离线架构图。
